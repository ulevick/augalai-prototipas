# Augalai: GUI prototipas (ND3)

Interaktyvus mobiliosios sąsajos prototipas: informacinis pradinis puslapis ir dvi DI funkcijos.

- **F1. Augalo atpažinimas iš nuotraukos** (persona Gintarė, gėlių parduotuvės konsultantė)
- **F2. Augalo ligų patikra iš nuotraukos** (persona Algis, sodininkas mėgėjas)

DI rezultatai imituojami pavyzdiniais duomenimis. Kaip pasiekti kiekvieną scenarijaus šaką, aprašyta pradinio puslapio skiltyje „Kaip išbandyti prototipą“.
